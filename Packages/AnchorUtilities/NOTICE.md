# Anchor Utilities

This native library incorporates Vorssaint v3.4.1, commit
`aea106cb5d52045c99810cf672da891d2a20b67d`, from
https://github.com/vorssaint/vorssaint-utils.

Original source attribution and SPDX headers are preserved. The release and
commit above identify the imported source. Existing notices in those files also
apply, including third-party work identified by the upstream authors.

Anchor's integration changes use a separate preferences domain and data directory,
one application lifecycle, explicit control ownership handover, host-managed windows,
Anchor branding, a feature library, Dashboard favorites, launcher discovery,
and Anchor-signed optional support components. No original brand assets are used.
The upstream application updater and original application delegate are not used.

Anchor, its logo, and its application identity are distinct from Vorssaint.
Vorssaint's name here identifies the original software and its authors, not an
endorsement of this fork.
